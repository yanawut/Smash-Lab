# Smash Lab

แล็บวิเคราะห์ท่าแบดมินตันบนเว็บ แต่ละแท็บนำหลักการจากคลิปสอนมาทำเป็นโมเดล แบบประเมินตัวเอง และแบบฝึก

- **ลูกตบ: จุดกระทบ** (อิงคลิป full-swing): โมเดลจุดกระทบ ประเมิน 8 หัวข้อ ภาพท่าถูก/ผิด และภาพเคลื่อนไหว
- **ตบกับหยอด** (อิงคลิป Jongnow TH): โมเดลวิถีลูกที่คิดแรงต้านอากาศ ตารางเทียบ และประเมินลูกหยอด
- **วิเคราะห์จากวิดีโอหรือภาพ**: จับท่าทางด้วย MoveNet **ในเครื่องผู้ใช้** ไม่อัปโหลดและไม่จัดเก็บไฟล์ มีโหมดตรวจท่าซ้อมรายหัวข้อ และภาพนิ่งของเฟรมที่ควรแก้
- **PWA**: ติดตั้งลงหน้าจอมือถือได้ และเปิดใช้แบบออฟไลน์ได้หลังเปิดครั้งแรก

เป็นเว็บแบบ static ล้วน (HTML/CSS/JS) ไม่ต้อง build และไม่ต้องมีเซิร์ฟเวอร์ฝั่ง backend

## โครงสร้างไฟล์

```
index.html            หน้าเว็บ
css/style.css         สไตล์ทั้งหมด (รองรับธีมสว่าง/มืด)
js/app.js             โค้ดทั้งหมดของแอป
vendor/tf.min.js      TensorFlow.js 4.20.0 (เก็บไว้ในโปรเจกต์ ไม่พึ่ง CDN)
models/               โมเดล MoveNet Lightning (.json + .bin ประมาณ 4.8 MB)
manifest.json         ข้อมูลแอปสำหรับ PWA (ชื่อ ไอคอน สี)
sw.js                 service worker สำหรับ cache และใช้งานออฟไลน์
icons/                ไอคอนแอป
.nojekyll             ให้ GitHub Pages เสิร์ฟไฟล์ตามที่เป็น
```

## รันบนเครื่องตัวเอง

ต้องเปิดผ่าน http server (เปิดไฟล์ `index.html` ตรง ๆ จะโหลดโมเดลไม่ได้) เลือกวิธีใดก็ได้:

```bash
# Python
python -m http.server 8080

# หรือ Node.js
npx serve .
```

แล้วเปิด http://localhost:8080

## Deploy ขึ้น GitHub Pages (ฟรี)

1. push โค้ดขึ้น branch `main` ของ repo นี้
2. ไปที่ **Settings → Pages**
3. ช่อง **Source** เลือก **Deploy from a branch**
4. เลือก branch **main** และโฟลเดอร์ **/ (root)** แล้วกด **Save**
5. รอ 1–2 นาที เว็บจะขึ้นที่ `https://yanawut.github.io/Smash-Lab/`

ทุกครั้งที่ push ขึ้น `main` เว็บจะอัปเดตเอง

## Deploy ขึ้น Cloudflare Pages (ฟรี เร็วในไทย)

1. สมัคร/ล็อกอิน https://dash.cloudflare.com แล้วไปที่ **Workers & Pages → Create → Pages → Connect to Git**
2. เลือก repo `Smash-Lab`
3. ตั้งค่า build:
   - **Framework preset:** None
   - **Build command:** เว้นว่าง
   - **Build output directory:** `/`
4. กด **Save and Deploy** จะได้ URL แบบ `https://smash-lab.pages.dev`
5. ถ้ามีโดเมนของตัวเอง ไปที่ **Custom domains** ของโปรเจกต์เพื่อผูกโดเมน

## อัปเดตเวอร์ชัน (สำคัญ)

แอปใช้ service worker เก็บไฟล์ไว้ในเครื่องผู้ใช้ ทุกครั้งที่แก้ไฟล์ใน `index.html`, `css/`, `js/` หรือ `models/`
ให้แก้ค่า `VERSION` ใน `sw.js` ด้วย เช่น `smashlab-v1` → `smashlab-v2` ไม่อย่างนั้นผู้ใช้เดิมอาจยังเห็นเวอร์ชันเก่า

## ข้อมูลส่วนตัว

- วิดีโอและภาพถูกเปิดในเบราว์เซอร์ของผู้ใช้เท่านั้น ไม่มีการส่งออกไปที่ใด และหายไปเมื่อปิดหน้า
- คะแนนแบบประเมินและประวัติความคืบหน้าเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้น
- ถ้าต่อไปจะเพิ่มระบบสมาชิกหรือเก็บข้อมูลบนเซิร์ฟเวอร์ ต้องทำหน้าขอความยินยอมและนโยบายความเป็นส่วนตัวตาม PDPA

## ข้อจำกัด

- วิเคราะห์จากภาพ 2 มิติมุมเดียว ตัวเลขทั้งหมดเป็นค่าประมาณ ควรถ่ายจากด้านข้างให้เห็นทั้งตัว
- โมเดลจับท่าทางมองไม่เห็นไม้และลูก บางหัวข้อจึงใช้เช็คลิสต์แทน
- แบบจำลองมุมลูก วิถีลูก และน้ำหนักคะแนนเป็นการตีความเพื่อใช้ฝึก ไม่ใช่ผลวัดชีวกลศาสตร์จริง

## ไอเดียต่อยอด

- วิเคราะห์จากกล้องสด (`getUserMedia`) ระหว่างซ้อม
- โมเดลที่แม่นขึ้น เช่น MoveNet Thunder หรือ MediaPipe Pose Landmarker
- ตามตำแหน่งลูกแบดในวิดีโอ เพื่อวัดความเร็วและความสูงที่ข้ามเน็ต
- ระบบสมาชิกและประวัติการซ้อมข้ามเครื่อง (เช่น Spring Boot + PostgreSQL)
